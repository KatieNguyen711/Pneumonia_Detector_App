# Pneumonia Detector

## Overview

Pneumonia Detector is an app that uses AI to analyze chest X-ray images and determine whether pneumonia is present.

The project consists of an Android app connected to a backend server that processes the images and returns predictions.

## Features

* Upload chest X-ray images
* AI-powered pneumonia detection
* Android mobile interface
* Server-client architecture

## How to Download Android App

Download the APK file called "app-debug.apk" from this repository and install it on your Android device.

## How to Use

1. Open the app on your Android device
2. Log in using the username "admin" and password "pneu123" (this will be changed later to have option to create accounts and save history)
3. Upload your chest X-ray image using the "+" button
4. Click the button with the loading indicator
5. View the AI prediction result
